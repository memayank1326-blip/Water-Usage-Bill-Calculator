# Water Usage Bill Calculator (C Programming)

A simple, menu-driven console application written in C that helps calculate water usage bills based on units consumed and saves billing records permanently[cite: 1].

## Objectives
* Apply C basics (structures, arrays, functions, pointers, loops) in a practical project[cite: 1].
* Learn file handling by saving and loading records permanently[cite: 1].
* Practise input validation so the program does not crash on wrong input[cite: 1].

## Features
| # | Feature | What it does |
|---|---|---|
| 1 | Add New Bill | Takes Consumer ID, Name, Units; calculates total bill |
| 2 | View All Bills | Shows all saved records |
| 3 | File Storage | Saves records to `water_records.txt` permanently[cite: 1] |

## Technologies
* **Language:** C[cite: 3]
* **Compiler:** GCC[cite: 3]
* **Storage:** Plain text file (`water_records.txt`)[cite: 1, 3]
